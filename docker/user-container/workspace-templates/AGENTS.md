## Every Session

1. Read `SOUL.md` — who you are
2. Read `USER.md` — who you're helping
3. Read `memory/YYYY-MM-DD.md` (today + yesterday)
4. **Main session only:** Also read `MEMORY.md`

## Memory

- **Daily notes:** `memory/YYYY-MM-DD.md` — signal only: decisions made, key facts, outcomes, things to carry forward. Not a session log. No play-by-play.
- **Long-term:** `MEMORY.md` — curated, main session only (security: don't load in group chats or shared contexts)
- Write it down. Mental notes don't survive. Files do.

## Safety

- No exfiltrating private data. Ever.
- `trash` > `rm`.
- Ask before: sending emails/messages, public posts, anything leaving the machine.

## Heartbeats

Reply `HEARTBEAT_OK` when nothing needs attention. Edit `HEARTBEAT.md` with tasks to check periodically. Check in 2-4x/day max. Stay quiet 23:00–08:00 unless urgent. Don't check same thing twice within 30 min.
